# java-llama.cpp — Android app icon

Square app-icon set built from the **shard-`J`** of the java-llama.cpp logo
(orange `#F65E00` on `#111111`). Generated by
[`../generate_app_icon.py`](../generate_app_icon.py), which reuses the icon
geometry from `generate_java_llama_logo.py` and drops the wordmark — so the icon
stays in sync with the logo. No font is embedded; the output is pure `<path>`.

## Regenerate

```bash
cd llama.cpp/projects/logo
python generate_app_icon.py -c java-llama-logo-config.json --android-set app-icon
```

Needs `resvg-py` for the PNGs (`pip install resvg-py`). Override colours with
`--fill` / `--background` (e.g. `--fill "#FAFAFA"` for the white-J variant).

## Files

| File | Use |
|---|---|
| `ic_launcher.svg` | Master: full square, J on `#111` (~72% fill). |
| `ic_launcher_foreground.svg` | Adaptive **foreground** master, transparent bg, J scaled into the safe zone. |
| `ic_launcher_background.svg` | Solid `#111` background master. |
| `ic_launcher-512.png` | **Play Store** icon (512×512). |
| `res/mipmap-*/ic_launcher.png` | Legacy launcher PNGs (48 / 72 / 96 / 144 / 192). |
| `res/mipmap-*/ic_launcher_foreground.png` | Adaptive foreground PNGs (108 / 162 / 216 / 324 / 432). |
| `res/mipmap-anydpi-v26/ic_launcher.xml` | Adaptive-icon descriptor (foreground + background). |
| `res/values/ic_launcher_background.xml` | `ic_launcher_background` colour resource (`#111111`). |

## Drop into an Android project

Copy `res/` into your module's `src/main/res/`. It provides both the legacy
square icons (pre-API-26) and the adaptive icon (API 26+): the launcher composes
`@color/ic_launcher_background` + `@mipmap/ic_launcher_foreground` and masks it to
the device shape.

**Safe zone.** The adaptive foreground keeps the J inside the 66dp-of-108dp
safe-zone circle, so nothing is clipped under circular / squircle / rounded-square
masks. If you re-tune the J geometry and its diagonal extremes grow, lower
`SAFE_FRAC` in `generate_app_icon.py` and re-check.
